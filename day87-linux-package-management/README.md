# Day 87 – Linux Package Management

## Objective
Learned how to manage software packages in Ubuntu using the APT package manager.

## Commands Practiced

```bash
apt update
apt upgrade -y
apt search nginx
apt show nginx
apt install tree -y
tree --version
apt list --installed
apt remove tree -y
apt purge tree -y
apt autoremove -y
apt-cache policy nginx
```

## Topics Learned

- Updating package repositories
- Upgrading installed packages
- Searching for software packages
- Viewing package information
- Installing packages
- Verifying installed software
- Listing installed packages
- Removing packages
- Purging package configuration files
- Cleaning unused dependencies
- Checking package versions and repositories

## Outcome

Successfully managed software packages using APT and understood the complete package lifecycle in Ubuntu.
