# Day 93 - System Resource Monitoring

## Objective
Learn how to monitor CPU, memory, disk usage, and system performance in Linux.

## Commands Practiced

```bash
free -h
top
htop
df -h
vmstat 1 5
iostat
```

## What I Learned

- Checked RAM and swap usage with `free -h`
- Monitored live processes using `top`
- Used `htop` for an interactive system monitor
- Checked disk usage with `df -h`
- Monitored CPU, memory and process statistics using `vmstat`
- Monitored disk I/O using `iostat`

## Result

Successfully monitored Linux system resources using standard monitoring tools inside an Ubuntu Docker container.
